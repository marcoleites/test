Data is pulled client-side from Yahoo Finance's public chart endpoint (5-minute bars, pre/post market included) and filtered to 4:00–6:00 PM ET. Yahoo does not officially support direct browser calls, so if a ticker fails to load with a network/CORS error, try serving this file from a local server instead of opening it directly (e.g. python3 -m http.server in this folder, then open http://localhost:8000), or reload — a couple of fallback routes are attempted automatically. Prices reflect the last available print in each 5-minute bucket and are not investment advice.
